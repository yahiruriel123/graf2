1. La etiqueta HTML <canvas> y el contexto 2D

El elemento <canvas> de HTML5 es un lienzo en blanco rectangular dentro de la página. Por sí solo no muestra nada: es solo un contenedor de píxeles. Para dibujar hay que usar JavaScript y pedirle al canvas un contexto de renderizado.

Estructura básica

<canvas id="miLienzo" width="400" height="400">
  Tu navegador no soporta canvas.
</canvas>
  • width y height definen el tamaño en píxeles (por defecto 300×150).
  • El texto interno es un contenido alternativo para navegadores que no lo soporten o lectores de pantalla.
  • Si el tamaño se cambia solo con CSS, la imagen se estira; conviene usar los atributos HTML.

Contextos de renderizado

Se obtienen con canvas.getContext(tipo). Un canvas solo puede usar un tipo de contexto.

ContextoDescripción
"2d"Dibujo en dos dimensiones: formas, rutas, texto, imágenes y gradientes. Es el que usa p5.js por defecto.
"webgl" / "webgl2"Gráficos 3D acelerados por GPU (basados en OpenGL ES).
"bitmaprenderer"Muestra de forma eficiente un ImageBitmap ya generado.
"webgpu"API moderna de GPU (disponible en navegadores recientes).

El contexto 2D

const canvas = document.getElementById("miLienzo");
const ctx = canvas.getContext("2d");

ctx.fillStyle = "rgb(30, 204, 91)";   // color de relleno
ctx.beginPath();                      // inicia una ruta
ctx.ellipse(200, 250, 100, 50, 0, 0, Math.PI * 2); // x, y, radioX, radioY, rotación, ángulo inicial, ángulo final
ctx.fill();                           // rellena la forma

Sistema de coordenadas: el origen (0, 0) está en la esquina superior izquierda; x crece hacia la derecha y y crece hacia abajo.

Métodos y propiedades principales:

  • fillRect(x, y, w, h), strokeRect(), clearRect(): rectángulos.
  • beginPath(), moveTo(), lineTo(), arc(), ellipse(), closePath(): rutas.
  • fill() y stroke(): pintan la ruta con fillStyle y strokeStyle.
  • lineWidth, font, fillText(), drawImage(), save()/restore(), translate(), rotate(), scale().

Demostración: el muñeco de nieve con canvas "puro"

function circulo(x, y, d) {
  ctx.beginPath();
  ctx.arc(x, y, d / 2, 0, Math.PI * 2);
  ctx.fill();
  ctx.stroke();
}

2. Fundamentos de p5.js

p5.js es una librería de JavaScript de código abierto, inspirada en Processing, creada para que artistas, estudiantes y programadores principiantes puedan hacer dibujos, animaciones e interacciones de forma sencilla. Por debajo, crea y maneja un elemento <canvas> con su contexto 2D, por lo que no hay que escribir getContext ni beginPath a mano.

Cómo se incluye

<script src="https://cdnjs.cloudflare.com/ajax/libs/p5.js/1.9.4/p5.min.js"></script>
<script src="sketch.js"></script>

Estructura de un sketch

function setup() {
  createCanvas(400, 400);   // se ejecuta UNA vez al inicio
}

function draw() {
  background(220);          // se ejecuta en bucle (~60 veces por segundo)
  ellipse(mouseX, mouseY, 50, 50);
}
  • setup(): configuración inicial; aquí se crea el lienzo con createCanvas(ancho, alto).
  • draw(): se repite continuamente y permite crear animación. Con noLoop() se ejecuta solo una vez (útil para dibujos estáticos como los de esta galería).
  • preload(), mousePressed(), keyPressed(): funciones de carga y eventos.

Funciones de dibujo usadas en esta galería

FunciónQué hace
background(r, g, b)Pinta todo el fondo de un color.
fill(r, g, b) / noFill()Color de relleno de las figuras / sin relleno.
stroke() / noStroke()Color del contorno / sin contorno.
ellipse(x, y, ancho, alto)Elipse o círculo centrado en (x, y).
rect(x, y, ancho, alto)Rectángulo con la esquina superior izquierda en (x, y).
line(x1, y1, x2, y2)Línea entre dos puntos.

Conceptos clave

  • Orden de dibujo: lo que se dibuja después se coloca encima. Por eso el suelo y el sol van antes que el muñeco.
  • Estado de estilo: fill() y stroke() se mantienen hasta que se cambian.
  • Variables: guardar valores como var x = 200; permite mover un dibujo completo cambiando un solo número (como en la rana).
  • Modo global vs. modo instancia: en modo global las funciones están disponibles directamente. En modo instancia (new p5(function(p){...}, "contenedor")) cada sketch vive aislado, lo que permite varios dibujos en la misma página. Esta galería usa modo instancia.

De Khan Academy a la web

Khan Academy usa ProcessingJS, cuya sintaxis de dibujo es casi idéntica a la de p5.js (ellipse, rect, fill...). Por eso el código original se puede reutilizar, pero ahora corre en un sitio web propio, con su HTML, su CSS y su JavaScript.

3. Diagrama del DOM de esta página

El DOM (Document Object Model) es la representación en forma de árbol que el navegador construye a partir del HTML. Cada etiqueta es un nodo; el nodo de arriba es el padre, los de abajo son sus hijos y los que comparten padre son hermanos. JavaScript puede leer y modificar este árbol (por ejemplo con document.getElementById, createElement y appendChild).

¿Cómo se relaciona con el código?

  • Nodos padre, hijo y hermano: head y body son hermanos y ambos son hijos de html.
  • DOM dinámico: los nodos en coral no están escritos en el HTML. En main.js, document.createElement("article") los crea y appendChild los agrega a div#galeria.
  • Canvas en el DOM: cada dibujo de p5.js es un elemento <canvas> dentro de su div.lienzo.
  • Seguridad: el código se muestra con textContent, que inserta texto sin interpretarlo como HTML.
